# نمونه درخواست‌ها

این درخواست‌ها را می‌توانید همان‌طور که هست کپی کنید و جای [قلاب‌ها] را با اطلاعات خودتان پر کنید. یادتان باشد که اول آدرس ریپو را در چت گذاشته باشید.

## ساخت کاراکتر شیت کامل
```
می‌خواهم برای برندم یک کاراکتر ثابت بسازی. بریف برندم ضمیمه است. شیت کامل را بساز و نشانم بده.
```
اگر بریف ندارید، خودش هفت سؤال کوتاه می‌پرسد و شیت را می‌سازد.

## تولید چهره و مستر شیت
```
از روی همین شیت، چهره را بساز و سه نسخه بده تا انتخاب کنم. بعد از انتخاب من، مستر شیت تصویری را هم بساز.
```

## ژست و حرکت
```
کاراکترم را در ژست «معرفی محصول به دوربین» بساز. شیت و عکس مرجع ضمیمه است.
```

## صحنه‌ی جدید
```
همین کاراکتر را در [کافه‌ی شب با نور گرم] بساز، با ژست [نشسته] از کتابخانه‌ی ژست‌ها. شیت و عکس مرجع ضمیمه است. چهره باید دقیقاً همان بماند.
```

## تست ثبات
```
ثبات کاراکترم را تست کن: سه صحنه‌ی متفاوت بساز و خودت جزءبه‌جزء چک کن چه چیزهایی یکی مانده و چه چیزهایی نه.
```

## ادامه در چت جدید
```
این شیت و کارت وضعیت کاراکتر برند من است: [پیست شیت + کارت وضعیت]
از همین‌جا ادامه بده؛ چیزی را از اول نساز.
```

## یک نکته
بعد از هر مرحله، «کارت وضعیت» را که پروتکل می‌دهد یک جا نگه دارید. همین کارت است که به چت‌های بعدی حافظه می‌دهد.
